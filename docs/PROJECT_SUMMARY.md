# ChCl-CA COSMO-실험-ML 작업 요약

> 범위: 이 문서는 COSMO 기반 초기설계, 1·2차 UV-Vis 자료 처리, Gaussian process 학습과 검증 등 함께 수행한 ML 작업만 정리합니다. 저장소의 `simulation/` 아래에 별도로 추가된 DFT·분광 작업 파일과 결과는 이 문서에서 생성·수정·검증하지 않았습니다.

## 1. 연구 질문

건식 조성변수인 choline chloride(ChCl):citric acid 몰비 변화에 따른 Ni 추출 관련 상대 UV 응답을 효율적으로 탐색하는 것이 목적입니다. 실제 침출 시료는 최종 용매 질량 기준 물 30 wt%를 포함한 ChCl-citric acid-water 조성입니다. 가능한 몰비를 모두 실험하기보다 다음 순환 구조를 만들었습니다.

```text
계산 기반 초기설계 -> 실제 실험 -> 지도학습 -> 신규 실험으로 사전예측 평가 -> 모델 갱신
```

COSMO-RS의 비이상성 지표를 직접 최적화하지 않았습니다. COSMO 값은 조성에 따른 용매 상호작용을 표현하는 입력 descriptor이고, 실제 응답과의 관계는 실험값을 통해 학습하도록 설계했습니다.

각 몰비가 독립적으로 DES를 형성한다는 점을 상평형 또는 열분석으로 확증하지 않았으므로, 본 문서에서는 이를 ChCl-citric acid 기반 수계 침출 조성 또는 DES 후보 formulation으로 구분합니다.

## 2. 실험계와 목표값

- 건식 조성변수: ChCl:citric acid 몰수비
- 실제 침출 조성: ChCl-citric acid에 최종 용매 질량 기준 물 30 wt% 포함
- 고정 조건: 60°C, 18시간 교반
- 건식 원료: 무수 ChCl과 무수 citric acid, 합계 3.0 g
- 물: 최종 용매 질량 기준 30 wt%
- 측정: 몰비당 UV-Vis spectrum 1개, 반복측정 없음
- blank: H2O blank이며 조성별 ChCl-citric acid matrix-matched blank가 아님
- 학습 목표: 각 spectrum의 300-400 nm 최대흡광도

이 목표값은 같은 측정조건에서 비교한 **상대적 UV proxy**입니다. 반복측정과 Ni 검량선이 없으므로 검량된 Ni 농도나 침출률(%)로 표현하지 않습니다.
300-400 nm endpoint는 1차 자료를 받은 뒤 원 spectrum을 검토해 정했지만, GP 학습과 후속 후보 선정 전에는 고정했습니다.

## 3. COSMO-RS 특성공간

ChCl 몰분율 0.05-0.95를 0.05 간격으로 나눈 19개 조성을 사용했습니다. 계산 온도는 25, 45, 65, 85, 100°C입니다.

주요 계산 항목은 다음과 같습니다.

- 두 성분의 활동도계수 `ln gamma total`
- 수소결합 에너지 항 `pm_E_hb`
- misfit 에너지 항 `pm_E_mf`
- 상호작용 면적 항 `pm_A_int`

정적인 sigma-profile과 sigma-moments는 동일 화학쌍의 몰비 회귀에서 변하지 않아 제외했습니다. `G^E/RT`와 활동도계수 분해항 일부도 정보 중복을 피하기 위해 주 모델에서 제외했습니다.

ChCl 계산은 중성 ion-pair 단일 성분 근사이고, 실제 60°C, 물 30 wt% 시료의 직접 계산값이 아닙니다. 계산 수렴 로그와 물리 정확성도 별도로 독립 검증하지 않았습니다. GP 입력에는 동일 조성에 정확히 연결한 45°C 및 65°C 무수계 descriptor 16개를 고정 reference로 사용했습니다.

## 4. 정답 없는 1차 실험설계

초기에는 침출 실험값이 없었으므로 성능예측 모델을 만들 수 없었습니다. 대신 45, 65, 85°C의 직접 계산값을 이용해 다음 거리를 결합했습니다.

- 조성 거리: 50%
- COSMO 특성 묶음 거리: 50%

19개 조성에서 5개를 선택하는 11,628개 부분집합을 전수평가하고, 전체 조성-특성공간에서 선택점까지의 평균 대표거리가 가장 작은 집합을 골랐습니다.

1차 몰비(ChCl:citric acid):

- 1:9
- 1:3
- 2:3
- 3:2
- 17:3

이 다섯 조건은 **고침출률 예측점이 아니라 COSMO-informed space-filling design**입니다.

## 5. 1차 실험과 GP 학습

1차 다섯 몰비의 원 spectrum에서 300-400 nm 최대흡광도 하나씩을 추출해 학습조건 5개로 사용했습니다. 파장 651개를 독립 표본으로 세지 않았습니다.

| ChCl:citric acid | UV proxy | peak wavelength |
| --- | ---: | ---: |
| 1:9 | 0.458322 | 341 nm |
| 1:3 | 0.212483 | 363 nm |
| 2:3 | 0.242907 | 369 nm |
| 3:2 | 0.162754 | 344 nm |
| 17:3 | 0.256298 | 343 nm |

고정 RBF-kernel Gaussian process regression을 NumPy로 구현했습니다.

- 입력: 물 제외 ChCl 몰분율 + 45/65°C COSMO descriptor 16개
- 출력: 300-400 nm 최대흡광도 UV proxy
- 거리 비중: 조성 전체 0.5, COSMO 네 묶음 전체 0.5
- length scale: 1.0
- 표준화 공간의 noise variance: 0.04
- 표준화: 매 훈련 fold 내부에서만 계산
- 사후 하이퍼파라미터 최적화: 수행하지 않음

초기 5점 leave-one-composition-out 결과는 평균 기준모델보다 GP가 나빴습니다.

| 모델 | MAE | RMSE | out-of-fold R² |
| --- | ---: | ---: | ---: |
| 훈련평균 | **0.09588** | **0.12641** | -0.562 |
| 몰분율-only GP | 0.14068 | 0.15802 | -1.441 |
| 몰분율+COSMO GP | 0.15202 | 0.16588 | -1.690 |

따라서 이 단계의 GP는 검증된 최적화 모델이 아니라 다음 실험을 설계하기 위한 탐색용 surrogate로 제한했습니다.

## 6. 동결 예측과 2차 실험

2차 결과를 받기 전에 1차 학습자료와 전처리 규칙, 모델과 특성 열 순서, 19개 조성격자의 예측평균과 내부 표준편차, 관련 입력과 출력의 해시를 저장했습니다.

실제 2차 신규 몰비는 1:19, 3:17, 1:4, 3:1, 19:1입니다.

핵심 원칙은 **Evaluate first, update second**입니다. 신규 실측값을 모델에 넣기 전에 고정된 사전예측과 먼저 비교했습니다. 다만 2차 다섯 점은 예측평균, 모델 내부 불확실성 및 조성공간 coverage를 결합해 선택한 비무작위 탐색점이므로, 이 비교는 일반 모집단에 대한 외부 검증이 아니라 선택된 후보에서의 전향적 대조입니다.

| ChCl:citric acid | frozen COSMO GP | measured UV proxy | measured - predicted |
| --- | ---: | ---: | ---: |
| 1:19 | 0.474389 | 0.598567 | +0.124178 |
| 3:17 | 0.369134 | 0.283992 | -0.085142 |
| 1:4 | 0.309264 | 0.622148 | +0.312884 |
| 3:1 | 0.212450 | 0.305575 | +0.093125 |
| 19:1 | 0.282106 | 0.330995 | +0.048889 |

| 모델 | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| 1차 훈련평균 | 0.16170 | 0.22030 | -1.1681 |
| 몰분율-only GP | **0.13194** | **0.15976** | -0.1402 |
| 몰분율+COSMO GP | 0.13284 | 0.16225 | -0.1761 |

두 GP는 평균 기준보다 오차가 작았지만, COSMO 포함 모델은 몰분율-only 모델보다 약간 나빴습니다. 특히 1:4의 높은 실측 UV proxy를 충분히 예측하지 못했습니다.

## 7. 10개 고유 몰비 통합 모델

실험팀 확인상 1차와 2차의 핵심 실험 및 측정조건은 같습니다. 스캔 상한은 850 nm에서 800 nm로 달랐지만, 학습 endpoint인 300-400 nm는 두 회차 모두 완전히 포함합니다.

2차 원본 ZIP과 가공 Excel의 원파장값 3,005개를 대조했습니다. 학습 표본은 파장점 3,005개가 아니라 신규 몰비 5개이며, 1차와 합친 뒤 총 10개 고유 몰비입니다.

| 10조건 leave-one-composition-out | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| 훈련평균 | 0.14152 | 0.16793 | -0.2346 |
| 몰분율-only GP | **0.11851** | **0.14645** | **0.0611** |
| 몰분율+COSMO GP | 0.12637 | 0.15617 | -0.0677 |

현재 데이터에서는 COSMO descriptor의 추가 예측 이점이 입증되지 않았습니다. 서로 다른 표본에서 계산한 5점 CV와 10점 CV를 직접 비교해 성능 향상으로 주장하지 않습니다. 또한 2차값은 통합 모델에 편입된 뒤 독립 검증자료로 다시 사용하지 않습니다.

## 8. 검증 체계

- **원자료 대조:** 2차 ZIP과 가공 Excel의 3,005개 원파장값, exact COSMO join, 파일 해시 확인
- **기준모델:** 훈련평균, 몰분율-only GP, 몰분율+COSMO GP를 동일 평가점에서 비교
- **교차검증:** 한 몰비 전체를 제외하는 leave-one-composition-out; 전처리는 훈련 fold에서만 계산
- **y-scrambling:** 5점은 120개 배열 완전열거, 10점은 회차 내 999회 제한 순열
- **적용영역:** 훈련 조성범위와 표준화 특성공간의 최근접거리로 보간과 외삽 표시
- **독립 재계산:** 본 GP의 Cholesky 계산과 별도 SVD 구현, 저장 모델 재로드, 입력-출력 해시 대조

결합자료의 조건부 순열 비율은 0.149였습니다. 교환가능성이 입증되지 않았으므로 정식 유의성이나 우연상관 배제의 증거로 사용하지 않습니다. 독립 계산의 최대 수치 차이는 약 1.47e-14였으며, 이는 코드 재현성을 확인한 결과이지 Ni 예측력 검증은 아닙니다.

GP의 내부 표준편차는 고정 커널 가정 아래 후보 탐색에 사용한 모델 기반 불확실성이며, 실험오차나 검증된 95% 신뢰구간이 아닙니다. 적용영역 표시는 조성범위와 최근접거리에 따른 운영상 경고일 뿐, 예측 신뢰성을 보증하지 않습니다.

## 9. 핵심 해석 한계

- y는 검량된 Ni 농도·침출률(%)이 아니라 300-400 nm 최대흡광도 UV proxy입니다.
- H2O blank만 사용했으며 조성별 ChCl-citric acid 매질 신호가 제거됐다고 볼 수 없습니다.
- Ni 흡수종, 검량선, 독립 정량과 반복측정이 없습니다.
- 1·2차에 공통 몰비 반복이 없어 회차 변동을 직접 추정할 수 없습니다.
- 실제 희석배수, 광경로, 금속원료 종류·투입량과 분리방법의 상세 기록은 미완전합니다.
- 1:19와 19:1은 1차 실험 조성범위 밖의 외삽 탐색점입니다.
- 2차값은 편입 전에 동결 모델을 평가했지만, 편입 후에는 갱신 모델의 독립 검증자료가 아닙니다.
- 1:4의 높은 국소 신호를 매끄러운 고정 GP가 충분히 설명하지 못했습니다.

## 10. 별도 DFT 작업과의 연결 범위

본 COSMO-UV-ML 작업에서는 DFT 계산이나 결과 검증을 수행하지 않았습니다. 저장소에는 별도 작업자가 올린 DFT 관련 자료가 존재하지만, 그 내용은 이 요약의 검증 범위 밖입니다.

향후 두 작업을 연결할 때에는 반복측정과 Ni 정량으로 확인된 대표 조성을 DFT 작업에 전달해야 합니다. DFT는 ML의 예측 성능을 검증하는 도구가 아니라, 해당 조성에서 국소 상호작용 가설을 해석·점검하는 별도 근거로 다뤄야 합니다.

연결 시 검토할 수 있는 비교 대상:

- 고 UV proxy 조건과 저 UV proxy 대조 조건
- ChCl-citric acid 수소결합 구조
- 가능한 Ni-citrate 및 chloride 포함 배위구조
- 물 분자가 포함된 국소 수화구조

가능한 계산 항목:

- 구조 최적화와 진동수 확인
- 상호작용 또는 결합에너지
- Ni-ligand 결합거리
- 전하분포와 charge transfer

두 작업을 연결하기 전에는 pH와 protonation state, Ni oxidation state와 spin multiplicity, chloride와 물의 포함범위, 여러 conformer, functional/basis set, solvation, frequency 및 BSSE 정책을 별도 DFT 담당자가 고정·검증해야 합니다. Cluster DFT가 고체 표면, 물 30 wt%, 여러 Ni 화학종과 동적 용매효과를 포함한 실제 침출공정 전체를 재현하지는 않습니다. 따라서 DFT 결과는 국소 상호작용에 대한 추가적인 기작 해석 근거로 한정해야 합니다.

## 11. 현재 결론

이 연구에서 확립한 것은 특정 최적 몰비가 아니라 다음의 재현 가능한 연구 흐름입니다.

```text
COSMO-informed initial design
-> round-1 experiment
-> fixed GP surrogate
-> frozen prospective evaluation
-> round-2 experiment
-> transparent model update
```

다음 단계에는 반복측정, Ni 검량 또는 독립 정량, 금속원료 미첨가 대조군, 추가 전향적 실험이 필요합니다. 그 후 별도로 검증된 대표 조성을 DFT 작업에 전달해 국소 상호작용 해석과 연결할 수 있습니다.
