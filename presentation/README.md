# 발표 대본 작성 자료

이 폴더에는 COSMO–UV–ML 작업을 발표 대본으로 정리하기 위한 문서만 모았다.

- [연구 전체 정리](PRESENTATION_RESEARCH_SUMMARY.md): 확인된 조건, COSMO 초기설계, 1·2차 실험, GP 모델, 사전평가, 검증 수치, 한계와 문헌
- [발표 대본 초안·질의응답](SPEAKER_SCRIPT_OUTLINE.md): 순서별 구어체 대본, 예상 질문, 발표 전 표현 체크리스트

## 사용 순서

1. `PRESENTATION_RESEARCH_SUMMARY.md`로 수치와 표현 범위를 확인한다.
2. `SPEAKER_SCRIPT_OUTLINE.md`의 문단을 발표 시간에 맞게 줄이거나 이어 붙인다.
3. 발표 직전에 초안 하단 체크리스트로 과장 표현을 점검한다.

> 핵심 범위: 모델의 표적은 검량된 Ni 침출률이 아니라 300–400 nm 최대흡광도 UV proxy다.
