①

핵심 워크플로우

문헌에서 모은 실험 데이터를 지도학습 모델로 예측(스크리닝)하고, 그 결과를 시뮬레이션과 실제 실험 두 갈래로 각각 검증해 세 값을 교차비교한다 — "새 물질 발견"이 아니라 빠른 탐색 방법론의 재현·검증이 이 프로젝트의 스토리입니다.

Step 1 · 문헌 데이터
문헌조사 → 지도학습 예측
기존 논문 실험값으로 모델 학습, 유망 조성 후보 스크리닝
→
Step 2 · 이원 검증
시뮬레이션 × 실제 실험
같은 후보를 계산화학 시뮬레이션과 소량 침출 실험으로 각각 확인
ML 예측값 · 시뮬레이션값 · 실험값 3자 비교 → 신뢰성 판별 → 결론 "짜고 치는 고스톱"이 아니라, 서로 다른 방법이 같은 후보를 가리키는지 보여주는 재현성 검증
②

민이 형과 논의·확인할 사항

통화에는 없었지만, 정리하면서 민이 형 확인이 필요하다고 판단된 부분만 모았습니다. 각 항목에 배경 → 확인할 질문 → 저희 팀 추천안 순으로 정리했습니다.

01 대상 용매 범위 — 이종 유기산 혼합계

배경: 통화에서 민이 형 전공(단일 산이 아닌 두 가지 유기산을 섞은 혼합 침출계)에 맞춰 대상 용매를 바꾸기로 했다고 들었음.

Q. 우선순위로 볼 산 조합(예: 구연산+말레산 등)과, 민이 형이 이미 참고 중인 논문이 있는지?
추천: 문헌상 실제 사례로 구연산+말레산 혼합 침출(Burgess et al., 2024)이 확인됨 — 온도·농도·시간 변수 구성이 유사해 출발점으로 적합할 수 있음. 민이 형 보유 논문과 교차 확인 필요.
02 민이 형 역할 확대 — 이론검토 + 실험 이중 부담

배경: 기존 역할은 "전체 파이프라인 검토"였는데, 통화에서는 여기에 더해 유일한 실제 침출 실험 수행자로 확정됨.

Q. 5주 안에 실제로 가능한 실험 횟수·재료·장비 여건은? 이론 검토 비중을 줄이고 실험에 집중해도 괜찮은지?
추천: 후보 이론 검토는 동현·영진이 문헌 근거로 1차 대체하고, 민이 형은 실험 실행에 집중하는 쪽으로 재배분 (⑤ 업무분담 참고).
03 EPA 프로그램 정식 명칭

배경: "민이 형이 검증용으로 찾은 미국 환경부 프로그램"이 통화에서 정확한 이름 없이 언급됨.

Q. 정확한 프로그램명과 용도(독성 예측? 생분해성 평가?)는?
추정: T.E.S.T.(Toxicity Estimation Software Tool) — EPA 공식 QSAR 기반 무료 툴로, 친환경 용매의 독성·생분해성 평가에 실제로 쓰임. 명칭 확인되면 민규 사용법 학습 범위를 확정.
04 테스트셋 방식 & 데이터 규모 목표 최종 확정

배경: 통화에서 동현·영진 형 사이에 이견이 있었던 부분. 저희가 QSAR·재료 스크리닝 분야 문헌 기준으로 방향을 검토했습니다 (근거는 ④번 섹션).

Q. 아래 추천안대로 진행해도 될지 민이 형 의견도 확인.
추천: 별도 대형 테스트셋 구축 대신 k-fold 교차검증 + 소량 외부검증 + y-스크램블링 병행, 데이터 목표는 "수만 개"가 아닌 "수백~수천 개 + 능동학습/베이지안 최적화로 보완"으로 조정.
05 계산화학 SW 및 실험 착수 시점

배경: 동현이 랩실 COSMO-RS/DFT 라이선스를 확인할 예정이나, 민이 형 랩실 자원과 일정 매칭이 필요.

Q. 8월 안에는 파일럿 실험 1~2건만 진행하고, 본 실험은 9월로 미루는 방향에 동의하는지?
추천: 8월은 "예비 결과" 확보까지만, 정밀 실험 검증은 9/1~9/20 사이로 이관 (⑦번 섹션 근거 참고).
③

전문용어 바로잡기

통화 중 몇 가지 용어가 혼용되거나 부정확하게 쓰였습니다. 포스터·보고서에는 정확한 용어를 쓰는 게 좋아서 정리했습니다.

통화 속 표현정확한 개념설명
"강화학습 하는 거잖아" 지도학습(Supervised Learning) 강화학습은 에이전트가 행동→보상을 반복하며 정책을 스스로 갱신하는 학습(예: 알파고). 팀이 하려는 건 이미 정답(실험값)이 있는 데이터로 모델을 학습시켜 새 조합을 예측하는 지도학습. "정답을 숨겨놓고 맞추게 한다"는 표현은 지도학습의 홀드아웃 검증을 뜻함 — 이 자체는 정확한 이해였음.
"이 모델이 다음엔 뭘 시도하면 좋을지 스스로 찾는다"는 뉘앙스 능동학습(Active Learning) / 베이지안 최적화(Bayesian Optimization) 화자들이 "강화학습"이라 부른 것의 실체는 오히려 이쪽에 가까움 — 모델이 다음에 계산·실험할 후보를 스스로 제안해 데이터가 적어도 효율적으로 탐색하는 기법. 데이터 부족 문제의 실질적 해법이므로 도입 검토 권장 (근거: ④번 섹션).
"스크리닝이나 결국엔 스캔이랑 비슷한 거야" 스크리닝(Virtual Screening) — 그대로 맞음 후보군 전체를 빠르고 저렴한 방법으로 훑어 유망한 소수만 추리는 과정. 정확하게 이해하고 사용함, 수정 불필요.
"방어학습" — 존재하지 않는 용어. 녹음 인식(STT) 오류로 "강화학습"이 잘못 표기된 것으로 추정.
(암묵적으로 사용) 논문 → ML → 스크리닝 QSAR (Quantitative Structure–Activity Relationship) 분자 구조·조성과 물성/효율 간 정량적 관계를 모델링하는 화학정보학 분야 명칭. 팀의 접근법은 사실상 QSAR의 확장판이므로, 포스터에 이 용어를 쓰면 방법론적 위치를 명확히 알릴 수 있음.
④

테스트셋 & 데이터 규모 — 전문가 기준 검증

테스트셋을 별도로 만들어야 하는가

동현은 "별도 테스트셋이 필요하다", 영진 형은 "요즘 AI 성능상 불필요하다"고 봤습니다. 화학정보학(QSAR)·재료 스크리닝 분야의 실제 관행을 찾아봤습니다.

  • OECD QSAR 모델 검증 5원칙 — 적용영역 정의와 통계적 검증을 요구하지만, "반드시 대형 테스트셋을 별도로 만들라"고 규정하지는 않음(방법론 중립).
  • Tropsha, "Best Practices for QSAR Model Development" (2010, Molecular Informatics) — 표준 워크플로로 내부 k-fold 교차검증 + 소규모 외부 검증셋 + 적용영역(applicability domain) 정의를 함께 쓸 것을 권고.
  • Golbraikh & Tropsha, "Beware of q2!" (2002, J. Mol. Graph. Model.) — 내부 검증 지표만으로는 예측력을 보장 못 한다고 경고, 외부 검증의 필요성을 강조.
  • Rücker et al. (2007, J. Chem. Inf. Model.) — y-스크램블링: 정답값을 무작위로 섞고도 모델이 성능이 나오면 우연 상관 — 소규모 데이터 QSAR에서 사실상 표준 검증 절차.
결론 — 양쪽 다 절반만 맞음. 대형 테스트셋을 미리 떼어놓을 필요는 없지만("영진 형 방향"), 데이터를 k-fold 교차검증으로만 쓰고 끝내는 것도 표준에는 못 미침("동현 우려"도 일리 있음). 가진 데이터로 k-fold(가능하면 nested) 교차검증을 주력으로 쓰고, 소량이라도 최근 논문 데이터 일부를 외부 검증용으로 떼어두고, y-스크램블링으로 우연 상관을 배제하는 절충안이 학계 표준에 가장 가깝습니다.

데이터가 정말 수만~수십만 개 필요한가

  • Topliss & Costello (1972, J. Med. Chem.) — 디스크립터(변수) 하나당 샘플 5~10개 이상을 하한선으로 보는 경험칙이 QSAR 분야에 널리 인용됨. "수만 개" 기준은 이 경험칙보다 훨씬 과도한 목표.
  • de Cerqueira Lima et al. (2006, J. Chem. Inf. Model.) — 화합물 195개로 여러 ML 모델과 교차검증·외부검증을 결합해 실제 출판된 QSAR 사례.
  • Xu, Ji, Li, Lu, "Small data machine learning in materials science" (2023, npj Computational Materials) — 소규모 재료 데이터 대응법을 정리: 디스크립터 축소, 정규화(Ridge/Lasso), 앙상블, 능동학습, 전이학습.
  • Ma, Kumar, Wang, Amanchukwu (2025, Nature Communications) — 단 58개 실험 데이터에서 출발해 베이지안 능동학습으로 100만 개 가상 후보 중 우수 전해질 4종을 찾아낸 사례.
결론 — "수만~수십만 개 필요"는 과장된 목표였습니다. 문헌에서 수집 가능한 수백~수천 개 규모로도 의미 있는 스크리닝이 가능하며, 오히려 데이터가 적을수록 능동학습/베이지안 최적화를 병행하는 쪽이 학계에서 실제로 검증된 접근입니다. 팀의 목표를 이 방향으로 재설정하는 걸 권장합니다.

전체 프로젝트 업무 분담

※ 참고: 기존에 단톡방에 있던 8/7 이전 역할 분담은 "금요일 회의 전까지 각자 해올 준비 과제"였고, 지금부터 아래는 8/31까지 전체 프로젝트를 어떻게 나눌지에 대한 새 분담안입니다 — 서로 다른 층위의 계획이니 헷갈리지 않게 구분해서 봐주세요.

동현 파이프라인 총괄 + 계산화학 시뮬레이션

  • 전체 파이프라인/일정 관리, 팀 간 산출물 연결(ML 결과 → 시뮬레이션 입력 → 실험 후보 전달)
  • 랩실 계산자원으로 후보 조성 시뮬레이션 병렬 실행(랜덤 시드 변경 다회 반복)
  • OpenAlex 등 문헌 검색 툴 팀 전체 설치·세팅
  • ML·시뮬레이션·실험 3자 비교표 작성 총괄
⚠ 총괄 + 시뮬레이션 실무를 동시에 맡아 업무 과다 우려 — 문헌조사 등 반복 작업은 민규에게 최대한 이관 권장.

영진 형 ML 스크리닝 모델

  • 문헌 데이터 기반 디스크립터 설계 및 데이터셋 정리
  • 변수별 최적 모델 비교(회귀/트리기반/앙상블 등) → 1차 스크리닝 모델 구축
  • k-fold 교차검증 + y-스크램블링 적용, 적용영역(AD) 확인
  • 필요 시 능동학습/베이지안 최적화 도입 검토 및 구현
  • 상위 후보 리스트(수치·근거 포함) 동현·민이 형에게 전달

민이 형 이론 검토(경량화) + 실제 침출 실험

  • 이종 유기산 혼합 침출계 관련 본인 보유 문헌·경험 공유 (이론 검토는 이 수준까지만, 상세 문헌조사는 민규가 보조)
  • ML/시뮬레이션이 추천한 후보 중 실현 가능한 조성 선별
  • 전지랩 자원으로 파일럿 침출 실험 수행 (8월은 1~2건, 본 실험은 9월)
  • EPA 검증 프로그램 정식 명칭·용도 확인해 민규에게 공유
  • 실험값을 동현·영진에게 전달해 3자 비교에 반영
⚠ 유일한 실험 수행자라 병목 위험 — 8월엔 최소 실험만, 본 실험은 9월로 분산해 부담 완화.

민규 문헌조사 보조 + 검증 프로그램 사용

  • OpenAlex로 침출 실험 데이터 보유 논문 1차 스크리닝 (영진 형·민이 형에게 후보 전달)
  • EPA 프로그램(T.E.S.T. 추정) 사용법 학습, 필요 시 팀 내 공유
  • 동현·영진의 반복적 문헌/데이터 정리 작업 분산 이관 대상 (업무량 완화 목적)
  • 데이터셋 정제 시 단위/조건 통일 등 보조 작업

현실성 검토 — 무엇을, 왜 바꿨는가

기존 5주 플랜(7/29 시작 기준)을 검토한 결과, 학부생 4인이 5주 안에 "문헌조사 → ML → 정밀계산 → 실험 완결"까지 전부 끝내는 건 비현실적이라 판단해 스코프를 조정했습니다. 근거를 정리합니다.

기존 계획8/31까지 정밀 실험 검증 포함 완결, 최종 후보 3~5개 실험 결과까지 확보
수정안8/31까지는 "1차 스크리닝 + 파일럿 실험(1~2건)"만, 본 실험·정밀검증은 9/1~9/20으로 이관

근거: 유사한 3단계 워크플로(전산 스크리닝 + 실험 검증)를 실제로 수행한 Amusa et al., "Advancing circular battery recycling by systematically screening novel deep eutectic solvents" (2025, Sustainable Materials and Technologies)는 COSMO-RS로 675개 조합을 스크리닝한 뒤 8개를 합성·실험 검증한 사례로, 정식 연구실 단위로 수개월 이상 걸리는 작업입니다. 학부생 4인이 다른 학업과 병행하며 5주 안에 전 과정을 완결하는 건 무리이므로, 발표에는 "1차 결과 + 방법론 제안 + 로드맵"으로 스토리를 짜는 게 현실적입니다.

기존 인식ML 학습에 수만~수십만 개 데이터 필요
수정안수백~수천 개 문헌 데이터 + 능동학습/베이지안 최적화로 보완

근거: ④번 섹션 참고. Topliss & Costello(1972)의 경험칙, de Cerqueira Lima et al.(2006)의 195개 데이터 QSAR 출판 사례, Ma et al.(2025)의 58개 데이터 기반 능동학습 사례 모두 소규모 데이터로도 유의미한 결과가 가능함을 보여줍니다. 목표를 낮추는 게 아니라 현실적인 데이터 규모에서도 통하는 검증된 방법(능동학습)으로 전략을 바꾸는 것입니다.

기존 인식테스트셋 필요 여부에 대한 이견 미해결
수정안k-fold 교차검증 + 소량 외부검증 + y-스크램블링 병행

근거: ④번 섹션. QSAR 분야 표준 관행(Tropsha 2010; Golbraikh & Tropsha 2002)을 따른 절충안으로, 동현·영진 형 양쪽 우려를 모두 반영합니다.

남은 리스크 — ML·시뮬레이션·실험 3자를 동시에 교차검증하는 선례는 조사 범위에서 확인되지 않았습니다. 이는 팀의 차별점이 될 수 있지만, 포스터에서 "최초 시도"라고 과장하기보다는 "기존 2단계 검증(전산+실험) 방법론에 ML 스크리닝을 결합해 확장했다"는 식으로 표현하는 게 학술적으로 안전합니다.
